# Create a brand new folder manually

1. Go to your repository on GitHub.
2. Click Add file and select Create new file.
3. In the file name box, type your Folder Name, followed by a forward slash (/). Typing the slash turns the text into a folder directory.
4. Because the folder cannot be empty, type a temporary file name in the new box that appears (e.g., README.md or .gitkeep).
5. Scroll down and click Commit changes.

# How to move stuff into a folder?


# Using the GitHub Web Editor (Drag & Drop)

This is the easiest way to move files or folders directly in your browser without the command line.
1. Go to your repository on GitHub and press the . (period) key on your keyboard to open the github.dev web-based editor.
2. Locate the file or folder you want to move in the left sidebar.
3. Click and drag the item directly into your destination folder.
4. Click the Source Control icon (the branching icon on the left sidebar).
5. Type a commit message (e.g., "Move file into folder") and click the checkmark or Commit & Push button to save the changes to your repository.

# Method 2: Editing the File Path (Single Files)
# If you only need to move a single text or code file and prefer the standard GitHub interface:

1. Navigate to the file you want to move inside your repository.
2. Click the pencil icon (Edit this file) in the upper-right corner of the file view.
3. In the filename input box at the top, change the path by typing your folder name followed by a forward slash right before the file name (e.g., change script.js to my-folder/script.js).
4. Scroll to the bottom, write a commit message, and click Commit changes.
