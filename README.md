# How To Do Things!!!!!!!!


 # How to code and save changes:

1. Open your repository on GitHub  (You're here) now press the . (period) key on your keyboard.
 
3. A browser version of VS Code will launch. You can create and edit your things.html, style.css, and script.js files right here.
4. To save your work, click the Source Control icon (the tree-branch symbol on the left menu), type a short message (e.g., "Fixed a menu"), and click Commit and Push.

# How to see your live site (GitHub Pages):

To see how your HTML/CSS actually looks without downloading it, we're using GitHub Pages:
1. Go back to your main repository page on GitHub.com.
2. Click Settings (the gear icon at the top).
3. On the left sidebar, click Pages.
4. Under "Build and deployment", change the Source dropdown to Deploy from a branch.
5. Under "Branch", click the dropdown, select main, and click Save.
6. Wait 1–2 minutes, then refresh the page. GitHub will give you a custom link (like username.github.io/repo-name) where you and your team can see your live website update every time you save code!



⚠️ CRITICAL STEP: Pull Before You Push!

Before you start working each day, always run this command to download any changes your teammates made. This prevents annoying code conflicts:
bash
git pull origin main
Use code with caution.
